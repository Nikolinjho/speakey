# Локальный пилот LoRA для Whisper Turbo

Пользователь одобрил реализацию предложенного пилота 02.11.2026. Работа выполняется в текущем изолированном worktree, существующие изменения окна исправлений сохраняются.

## Результат

Отдельный CLI обучает LoRA декодера исходного Whisper large-v3-turbo на подтверждённом корпусе, сравнивает базовую и обученную модель на одинаковых настройках и сохраняет адаптер с протоколом. Установка в Speakey выполняется отдельным шагом после проверки качества.

## Условия

Обучение и оценка выполняются без сети. Аудио, эталоны, адаптеры и отчёты остаются вне Git. Базовые веса не меняются. Дни записи не смешиваются между обучением и валидацией. Пустой эталон допустим только для подтверждённой тишины. Примеры длиннее 30 секунд не усекать для обучения, а явно исключать с причиной. При оценке длинное аудио обрабатывается целиком штатным long-form generate.

Первый прогон: LoRA rank 8, alpha 16, dropout 0, q/v декодера, замороженный энкодер, batch 1, 60 шагов, lr 0.0001, seed 42. Базовая и обученная модели оцениваются одним backend, с одинаковым greedy-декодированием и языком auto. Валидация на двух старых примерах не считается независимой итоговой проверкой.

## Проверки

Исходные проверки: `python3 -m unittest discover -s Tests/SpeechEvaluation -q` – 80 тестов, OK.

Новые проверки сначала запускаются до реализации. Затем выполняются весь набор SpeechEvaluation, реальные проверки маленького Whisper, проверка MPS на настоящей модели и полный пилот. В финальном протоколе обязательны полный набор ID гипотез, хеши входов и весов, число выполненных шагов, изменения адаптера, сравнение WER/CER и фактический статус.
