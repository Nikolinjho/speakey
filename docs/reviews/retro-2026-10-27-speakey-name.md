# Переименование Speakey

Пользователь выбрал название Speakey, затем иконку 04. При установке иконки название в интерфейсе осталось Keyboop. Пользователь указал на это после установки.

Причина: проверялись ресурс иконки, подпись и запуск, но не результат выбранного переименования. Название находилось отдельно в настройках, меню, локализации и метаданных сборки.

Исправление проверяется по четырём наблюдаемым признакам: файл Speakey.app, имя запущенного приложения Speakey, заголовок окна Speakey и надпись Speakey в шапке настроек. Дополнительно проверяются текущие локализованные тексты, сборочные имена и сохранение разрешений после смены пути.

Изменения общих инструкций не требуются. Протокол и снимок установленного приложения сохраняются рядом с проверкой этой задачи.
