# Ретроспектива 13.11.2026

## Наблюдения

- Ника заметил отсутствие полей и отличие страницы автодополнения от остальных настроек.
- В истории ветки уже есть отдельная правка выравнивания заголовков новой страницы.
- Нативная проверка до исправления измерила поля первой строки: 0 pt сверху и снизу.
- Первая проверка исправления остановилась на временном отказе macOS снять окно голосового набора.
  Повторный запуск сохранил снимки и прошёл в обеих темах.

## Причина

Страница повторяла внешний вид строк, но пропустила ограничение высоты из
`DetailVC.settingRow`. У многострочных подписей AppKit сжимал вертикальные поля.
Проверка ширины страницы этот дефект не обнаруживала.

## Изменения

- Строки учитывают высоту текста вместе с полями.
- Нативная проверка измеряет поля автодополнения и сохраняет снимки страницы.
- Правила оформления собраны в `docs/development/settings-ui.md`, ссылка добавлена в README.
- Дополнительных изменений навыков или правил агента не предлагается.

## Продолжение автодополнения

- Ника поручил проходить этапы самостоятельно. Дальнейшие решения по реализации принимаются в согласованном объёме без повторных запросов разрешения.
- Изменение Swift-файла во время полной сборки завершает компиляцию ошибкой. Сборку для проверки начинают после завершения ревью и фиксируют состав исходников до её окончания.
- Запрет клавиши и защита от автоповтора проверяются для всех назначаемых действий. Автоповтор ручного вызова сохраняет поколение исходного запроса.

## Настройки приложений и корпус

- Доменные правила исключены по прямому решению Ники. Браузеры настраиваются как приложения.
- Геометрию карточек проверяют отдельно: отсутствие обрезанных контролов не доказывает, что карточка занимает всю колонку.
- Метаданные файла задаются до атомарной замены. Ошибка после записи не должна оставлять память и диск в разных состояниях.
- Обычная резервная копия 14 ГБ данных не поместилась при свободных 12 ГБ. Установщик переведён на независимые APFS-клоны с проверкой содержимого. Дополнены проверки независимости копии и отказа диска.

## Редактирование и выбор слов

Сигналы сессии: несколько полных пересборок после нативных проверок, зависание собственного NSTextView, пустые списки после второго запуска приложения и отказ AX-записи в Safari. В git уже есть отдельный smoke-тест CompletionEngine. При добавлении проверки владения он был временно перезаписан, затем восстановлен. Новая проверка вынесена в CompletionEngineOwnership.

Выводы:

- Собственный AX-элемент обслуживается AppKit напрямую. Запись с фоновой очереди может взаимно заблокировать layout и NSTextStorage. Весь собственный AX-путь перенесён на main.
- Чистая функция обработки текста не доказывает поддержку транспорта конкретного приложения. Safari читает AX-диапазоны, но не поддерживает нужную AX-запись. Для него транспорт выбирается до записи: Unicode в PID с проверкой поля после каждой части.
- Stop без собственного Process не имеет права удалять общий pid/socket. Ошибка ломала второй запуск для открытия настроек и скрывала PID осиротевшего помощника перед killStale.
- Нативные тесты должны использовать отдельный socket/pid и сохранять существующие smoke-тесты. Отказ bind из sandbox не является отказом модели.
- Панели подсказок имеют уровень 25. Обычный список окон не показывал их, для проверки нужен on_screen_only:false.
- Control+Option не доставлялся в окно записи в текущем окружении. Физическую команду сначала подтвердили в recorder через Control+Command.
- TTL списка восемь секунд требует объединять вызов, снимок и принятие в один тестовый сценарий. Пауза между отдельными действиями агента может превратить проверку принятия в обычный набор цифры.
- Граничные тесты покрывают пробелы слева и справа, пунктуацию, UTF16, смену поля и выбранного диапазона. Обычное «список показался» не проверяет сохранность соседнего текста.

Изменения инструкций и навыков не предлагаются. Исправления продукта, изоляция smoke-теста и регрессионные проверки вошли в этот этап.
