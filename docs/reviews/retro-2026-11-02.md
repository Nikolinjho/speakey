# Ретро 02.11.2026

## Сигналы

- В диалоге пользователь попросил убрать ручной выбор сессии и назначения примера. Для исправления расшифровки эти поля создавали лишнюю работу.
- Проверка типов сначала остановилась из-за одного кеша модулей, доступного через пути `/tmp` и `/private/tmp`. Новый отдельный каталог кеша позволил выполнить проверку.

## Выводы

- Служебная разметка корпуса должна определяться по времени создания записи. Пользователь подтверждает дословный текст и при необходимости задаёт оформление.
- Для временных проверок Swift нужен отдельный каталог кеша с одним абсолютным путём.

## Изменения

- В рамках задачи ручные поля заменены датой создания, группировка и экспорт времени выполняются автоматически.
- Изменения общих правил и навыков не предлагаются: постоянная инструкция для этого изменения не нужна.


## Сравнение GigaAM

- Проверочный синтетический WAV оказался в PCM16, тогда как личный корпус экспортирован в Float32. Строгая проверка остановила запуск до модели.
- Проверочный WAV преобразован в Float32 без потери значений исходного PCM16. На личных записях преобразования не выполнялись.
- Перед пробным запуском нового движка формат синтетического примера нужно сверять с форматом корпуса. Изменения общих правил и навыков не требуются.


## Пилот Whisper LoRA

- Общая проверка корпуса допускает пустой эталон без признака тишины. Подготовка данных для обучения отдельно отклоняет такие записи, чтобы модель не училась подавлять речь.
- Хеш аудио для поиска утечки между днями вычисляется по WAV. Сведения происхождения в JSONL не заменяют проверку фактических байтов.
- Улучшение на обучающих фразах не переносится на отложенные автоматически. В этом пилоте ошибки обучения сократились, ошибки валидации остались прежними. Автоустановка результата не выполняется.
- Изменения общих правил и навыков не требуются.

- Python 3.12 для повторного расчёта метрик должен совпадать с окружением обучения: старый системный Python иначе округляет сумму длительностей. Ошибки слов при этом совпадают.
- В автоязыке изменённая модель может выбрать другой язык и подсказку. При сравнении настроек отделяем эти результаты модели от статических параметров запуска.
