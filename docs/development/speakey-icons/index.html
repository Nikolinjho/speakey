С чего я бы выбирал

Голосовая клавиша точнее объясняет название: речь и клавиатура объединены в одном знаке.

Речевая S проще по форме и лучше подходит для маленькой иконки. Её удобно развить в монохромный знак для строки меню.

SVG: viewBox 256 × 256. Скруглённая подложка входит в файл, пространство за ней прозрачное. Это варианты иконки приложения. Для выбранного знака иконку строки меню подготовим отдельно.
