# Проверка локального повторного распознавания

30.10.2026, MSK. Два синтетических клипа, без микрофона и личных записей. Это проверка связки Swift CLI, Python runner и метрик, а не сравнение моделей или оценка качества на голосе Ники.

## Результат

| Вход | Сырой ответ Turbo | Декодирование | Весь дочерний процесс |
| --- | --- | --- | --- |
| Milena, 3,728 секунды | Привет! Сегодня я проверяю локальное распознавание речи. | 0.633 с | 2.628 с |
| Цифровая тишина, 1 секунда | Продолжение следует... | 0.445 с | 1.659 с |

Фраза для синтеза: «Привет. Сегодня я проверяю локальное распознавание речи.» Все семь слов распознаны. Отличие точки и восклицательного знака учитывается отдельно от лексической точности.

На тишине сырой ответ содержит два выдуманных слова. Текущий обычный путь Speakey с нулевым RMS не вызывает модель. Runner намеренно проверяет модель напрямую. Этот результат не означает, что установленное приложение вставляет такую фразу при тишине.

Для каждого файла процесс запускается заново. Время включает загрузку модели и служебную работу. По двум клипам нельзя судить о средней точности, p95 или времени повторной диктовки. Суммарный WER этих двух тестов не используется как показатель качества модели.

Промежуточные файлы: `/private/tmp/speakey-speech-smoke-20261030`. Они могут быть очищены системой. В `turbo-run/run.json` сохранены конфигурация, её хеш, хеши входов и время начала в MSK. `hypotheses.jsonl` содержит ответы, `smoke-report.json` – счётчики ошибок.

```bash
python3 Tools/SpeechEvaluation/runners.py /private/tmp/speakey-speech-smoke-20261030/manifest.jsonl \
  --executable /private/tmp/Speakey_speech_evaluation.app/Contents/MacOS/Speakey \
  --model "$LOCAL_GGML_MODEL" --language ru --stage raw \
  --output /private/tmp/speakey-speech-smoke-repeat
```

Нужен существующий путь к локальной модели в `LOCAL_GGML_MODEL`. Команда не скачивает веса. Выходной каталог должен быть новым.

После этого реальный прогон выявил различный порядок JSON-ключей Foundation и Python. Формат исправлен и проверен отдельной регрессией. Итоговый runner успешно обработал оба клипа, проверил все хеши и сформировал отчёт.
