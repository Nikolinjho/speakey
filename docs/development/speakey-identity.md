# Идентичность Speakey

Executable: `Speakey`. Локальная сборка: `dev.speakey.app.dev`, релизная:
`dev.speakey.app`. Данные: `~/Library/Application Support/Speakey`, журнал
раскладки – в каталоге bundle ID. Имена переменных окружения начинаются с
`SPEAKEY_`. Настройки, hotkey и правила при переносе сохраняются.

Сборка использует постоянный сертификат по SHA-1
`749281C2A0E19FC82DA85918A28F5BCC195C5597`, либо явно заданный `SPEAKEY_SIGN_ID`.
Переименование подписи не создаёт новую криптографическую идентичность.

В приложении нет пожертвований, формы отправки отчётов, внешних контактов,
ленты релизов и механизма автообновлений. Модели голоса скачиваются по явному
действию с HuggingFace через проверенный загрузчик. Локальные журналы остаются
локальными. Обязательные уведомления об авторстве находятся в `LICENSE`,
библиотеки и модели перечислены в `THIRD_PARTY.md`.

Перед заменой приложения установщик проверяет staged bundle и создаёт
резервную копию. Перенос зашифрованной истории требует сохранения её ключа.
Смена bundle ID требует повторной выдачи разрешений macOS пользователем.
Исторические протоколы проверок доступны в истории Git.
