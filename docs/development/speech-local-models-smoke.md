# Проверка запуска трёх локальных моделей

30.10.2026, MSK. Проверены Whisper large-v3-turbo, Parakeet TDT 0.6B v3 int8 и Qwen3-ASR 1.7B 8bit. Все три действительно загрузили локальные веса и обработали одинаковые WAV. Это проверка запуска, а не оценка качества на голосе пользователя.

## Вход и результаты

Локальный голос macOS Milena произнёс «Привет, сегодня я проверяю локальное распознавание речи». Длительность – 3,728 с. Второй WAV – одна секунда цифровой тишины. В обоих случаях mono Float32, 16 kHz. Личные записи и микрофон не использовались.

| Модель | Слова фразы | Ответ на тишину | Декодирование фразы, с | Весь процесс фразы, с |
| --- | --- | --- | --- | --- |
| Whisper Turbo | 7 из 7 | «Продолжение следует...» | 0,633 | 2,628 |
| Parakeet v3 int8 | 7 из 7 | пустой | 0,073 | 12,461 |
| Qwen3-ASR 1.7B 8bit | 7 из 7 | «Да.» | 3,343 | 8,302 |

Пунктуация различалась. Нормализованные слова фразы совпали у всех моделей. Ложные ответы на тишину входят в итоговый счётчик вставок отчёта.

Для каждого WAV запускался новый процесс. Полное время включает загрузку модели, проверку хешей и запуск библиотек. Первая загрузка CoreML особенно влияет на результат Parakeet. Это разные условия готовности кешей, поэтому по таблице нельзя выбирать самый быстрый движок для повторной диктовки или оценивать p95.

Обычная диктовка Speakey отбрасывает цифровую тишину по RMS до модели. Проверочный CLI намеренно передаёт её модели. Этот результат не доказывает, что установленное приложение вставляет эти фразы. Parakeet возвращает текст после обработки FluidAudio, Qwen – после обработки mlx-audio. У Whisper взят результат до удаления эха подсказки. Общая обработка VoiceController и личный словарь не применялись.

## Веса и окружение

| Модель | Хеш модели из run.json |
| --- | --- |
| Whisper Turbo | `1fc70f774d38eb169993ac391eea357ef47c88757ef72ee5943879b7e8e2bc69` |
| Parakeet | `228748ca4ec12a17e6ae156deb4a0e6c4e7cd9c125d3f7c15f7c00ba31d717e9` |
| Qwen | `8bce5adfb5d9bab45c387d249d0005de701b746eba10932da2904d2d5930464e` |

Whisper хешируется одним GGML-файлом. Parakeet – манифестом реально загружаемых компонентов v3 int8. Qwen – манифестом локальных файлов с дополнительной проверкой байтов по закреплённым upstream-хешам.

Qwen: `mlx-community/Qwen3-ASR-1.7B-8bit`, revision `a8379a2e2f9e313c9292cdf1af4055ab56d50d55`. Среда Python 3.12, mlx-audio 0.6.3, mlx 0.32.4, transformers 5.22.1. Полный список закреплён в `Tools/SpeechEvaluation/requirements-qwen.lock`. Установленные MLX wheels требуют macOS 26+ arm64. Это ограничение отдельного проверочного окружения, а не новая минимальная версия Speakey.

Веса Qwen скачаны отдельной явной командой подготовки. Во время распознавания используются локальный tokenizer, отключённый Hub и защита сетевых вызовов Python. Это не сетевой запрет на уровне ОС. Пользовательское аудио не отправлялось. Проверка Whisper/MLX выполнялась вне песочницы после воспроизводимой ошибки выделения Metal-буфера в песочнице.

## Повторение

Результаты находятся в `/private/tmp/speakey-speech-smoke-20261030`: общий `manifest.jsonl`, каталоги `turbo-run`, `parakeet-run`, `qwen-run` с гипотезами и протоколами, отчёты метрик. Это временные файлы, система может их удалить.

```bash
python3 Tools/SpeechEvaluation/runners.py \
  /private/tmp/speakey-speech-smoke-20261030/manifest.jsonl \
  --engine qwen \
  --executable "$PWD/vendor/speech-evaluation/venv/bin/python" \
  --model "$PWD/vendor/speech-evaluation/models/qwen3-asr-1.7b-8bit" \
  --language ru --timeout 300 \
  --output /private/tmp/speakey-qwen-new-run

python3 Tools/SpeechEvaluation/evaluate.py evaluate \
  /private/tmp/speakey-speech-smoke-20261030/manifest.jsonl \
  /private/tmp/speakey-qwen-new-run/hypotheses.jsonl \
  --output /private/tmp/speakey-qwen-new-report.json
```

Для Parakeet указываются `--engine parakeet`, executable проверочного приложения и каталог `parakeet-tdt-0.6b-v3`. Для Whisper – `--engine whisper`, тот же executable и файл GGML. Полные команды подготовки и требования к корпусу – в [инструкции стенда](../../Tools/SpeechEvaluation/README.md).

## Что остаётся проверить

Нужен подтверждённый корпус речи пользователя с новыми сессиями для итоговой проверки. В него должны войти тихая речь, паузы, числа, отрицания, имена, рабочие термины, смешанный язык и длинные фразы. На этих данных сравниваются точность, задержка после загрузки и объём памяти. Синтетическая фраза не является основанием заменить Turbo или обещать идеальное распознавание.
