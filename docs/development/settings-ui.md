# Оформление настроек Speakey

Образцы для новых страниц – разделы «Переключение», «Голосовой набор» и «Общие».
Общие размеры `DS` и карточки `CardView` находятся в `Sources/Speakey/SettingsDesign.swift`.
Оформление строк задано в `DetailVC` в `Sources/Speakey/SettingsWindow.swift`.

| Элемент | Оформление |
| --- | --- |
| Окно подробных настроек | 760 × 560 pt по умолчанию, длинные страницы прокручиваются |
| Колонка | Ширина до 528 pt, внешние поля 20 pt |
| Заголовок страницы | Системный шрифт 20 pt, semibold, выравнивание слева |
| Заголовок группы | `DetailVC.eyebrowLabel`, коралловый, 11,5 pt |
| Между элементами страницы | `DS.itemGap`, 6 pt |
| Перед заголовком следующей группы | Дополнительный промежуток 6 pt |
| Карточка | `CardView`, адаптивная заливка и граница |
| Строка подробных настроек | Минимум 35 pt, поля 5 pt сверху и снизу, 11 pt по бокам |
| Заголовок строки | 12 pt, основной цвет текста |
| Подпись строки | 11 pt, вторичный цвет текста |
| Разделитель | `HairlineView`, отступ слева 14 pt |
| Контрол | Справа, без сжатия по ширине |

У многострочной подписи высота строки должна быть не меньше высоты текстовой
колонки плюс оба вертикальных поля. Одного `edgeInsets` у `NSStackView`
недостаточно: при раскладке AppKit может сжать поля до нуля.
Пример ограничения – `DetailVC.settingRow`.

Вертикальный стек страницы выравнивается по `.leading`. Карточки, строки
и переносимый текст привязаны по ширине к стеку. `.width` без явной привязки
не гарантирует выравнивание заголовков и подписей слева.

Перед установкой страницу проверяют в светлой и тёмной темах при стандартном
размере окна. Проверка геометрии и снимки соседних разделов:

```bash
bash scripts/test-compact-settings.sh /path/to/Prepared.app /private/tmp/speakey-settings-check
```

Для автодополнения проверка также измеряет вертикальные поля строк.
Снимок страницы сохраняется как `dark/autocomplete.png` и `light/autocomplete.png`.
