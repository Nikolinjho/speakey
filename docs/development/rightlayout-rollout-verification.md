## Работа установленного процесса

После замены подписи macOS первоначально вернула AX=false и InputMon=false. Ника выдал оба доступа. В 16:20:56 MSK именно установленная версия записала `launched` с AX=true и InputMon=true, затем `engine STARTED ok (AX=true InputMon=true)`. Это подтверждение установленного процесса, отдельное от успешных разрешений временного стенда.

В 16:24:33 MSK журнал содержал 1053 наблюдения, из них 32 после установки. Девятнадцать новых записей содержали настоящие оценки `rightlayout-ensemble-20-v1`, ожидаемый SHA модели, mode=observe и все девять классов. Старые ID наблюдений, случаев и правила сохранены. Сбор включён. [Протокол установки](artifacts/rightlayout/12-installation.json), [агрегаты сбора](artifacts/rightlayout/13-collection.json).

Новых подтверждённых ошибок после установки пока нет. Два прежних случая длиной два символа не проверяют помощь для 4–16 символов. Содержимое личных слов в отчёт не экспортировалось. Наблюдения движка не превращаются в правильные метки автоматически.

Все 19 нейронных записей в снимке содержат `stale`. Это не измерение задержки модели: в observe проверка свежести при `emit` может выполняться после привязки завершённого слова, когда revision уже изменился. Для причинного вывода нужен отдельный замер.
